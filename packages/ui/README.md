# UI Design System Package (`packages/ui`)

Shared design system and component library built for the desktop client and future web interfaces.

## Features
- **Design Tokens**: Standardized HSL color palettes, typography scales, spacing, shadows, and status colors.
- **Accessible Components**: Keyboard-navigable dialogs, data tables, split-pane viewers, badge pills, dropdowns, and toast notifications.
- **Domain Components**:
  - `EvidenceHighlight`: Text highlighter linking extracted fields to original email text.
  - `SlaCountdown`: Visual countdown timer indicating overdue or upcoming SLA deadlines.
  - `CaseStatusBadge`: Distinct, non-color-only status badges.
